# sample-site

Small Hugo site fixture used by OxiPress for manual + integration testing.

Roughly 10 content files spread across two sections (`posts/`, `docs/`),
plus the section indexes. Layouts are minimal stubs sufficient to drive
Hugo serve from Phase 5 onward; Phase 1–4 only need the directory
structure.

Do **not** depend on this fixture for production examples — its only job
is to be a known-good Hugo project the OxiPress test suite can open.
